# ⚡ IoT Based Energy Meter Monitoring System

An IoT-based smart energy monitoring system designed to measure, analyze, and visualize electricity consumption in real time.  
The system uses sensors and a microcontroller to collect energy data and transmit it to a cloud platform for remote monitoring and analysis.

---

## 🚀 Features

- ⚡ Real-time energy consumption monitoring  
- 📊 Live data visualization on cloud platform  
- 🌐 Remote access to energy usage data  
- 🔌 Voltage, Current, Power, and Energy measurement  
- 📡 Wireless data transmission using Wi-Fi  
- 📈 Historical data tracking and analysis  

---

## 🛠️ Technologies Used

- Microcontroller: ESP32  
- Sensor Module: PZEM-004T (Energy Meter Sensor)  
- Communication: Wi-Fi (HTTP / MQTT Protocol)  
- Cloud Platform: ThingSpeak / IoT Cloud *(based on your implementation)*  
- Programming: Embedded C / Arduino  

---

## 📂 Project Overview

This system monitors electrical parameters such as voltage, current, power, and total energy consumption using the PZEM-004T sensor connected to an ESP32 microcontroller.  
The collected data is transmitted over Wi-Fi to a cloud platform, enabling users to monitor energy usage remotely in real time.

---

## 🎯 Objectives

- Enable smart monitoring of electricity consumption  
- Improve energy efficiency and awareness  
- Provide real-time and remote data access  
- Reduce manual meter reading efforts  

---

## ⚙️ How It Works

1. Sensor (PZEM-004T) measures electrical parameters  
2. ESP32 processes the sensor data  
3. Data is transmitted via Wi-Fi  
4. Cloud platform stores and visualizes data  
5. Users can monitor energy usage remotely  

---

## 📊 System Architecture

Sensor (PZEM-004T) → ESP32 → Wi-Fi → Cloud Platform → User Interface
